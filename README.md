# neo_reversi

Unity 製のオセロ（リバーシ）。ブラウザ（WebGL）で遊べます。

## ▶ プレイ

**https://tomsato42.github.io/neo_reversi/**

## 遊び方

- 盤面のマスをクリックして石を置きます。置けるマスには返せる枚数がヒント表示されます。
- 黒・白それぞれの **AI トグル**を ON にすると、そのプレイヤーを AI が操作します（AI 対 AI 観戦も可能）。
- 相手の石を 8 方向で挟むと裏返せます。両者とも打てる手が無くなったら終局です。

## スコア計算（大返しボーナス）

「たくさん返すほど 1 枚あたりの価値が上がる」ようにしています。
一手で返した枚数を `flipped` とすると、加点は **三角数** `flipped × (flipped + 1) / 2`：

| 一手で返した枚数 | 加点 |
|:---:|:---:|
| 1 | 1 |
| 2 | 3 |
| 3 | 6 |
| 4 | 10 |
| 5 | 15 |
| 6 | 21 |

1 枚多く返すごとに、その手の価値が前より大きく増えるため、**大返しほど爆発的にスコアが伸びます**。
盤上の石数には依存しないので、序盤・終盤で有利不利は出ません。

## 使用技術

- Unity 6000.3.9f1 / WebGL
- AI 思考（ミニマックス探索）はバックグラウンドスレッドで実行し、フレームレートを維持
